# 研究小間占位監測 · 3D 系統情境 Demo

用網頁即時渲染的 3D 動畫（約 75 秒），展示「研究小間占位監測系統」在真實情境中的完整流程：從牆角的監測裝置、熱成像資料處理，到監控網頁與工讀生巡查。

## 使用方式

1. 用 Chrome 或 Edge 直接開啟 `research-cubicle-demo.html`。
2. 載入完成後會自動播放。

需要網路連線，因為 3D 函式庫（three.js）與字型從 CDN 載入。

## 操作

| 操作 | 功能 |
| --- | --- |
| 播放鍵 / 空白鍵 | 播放、暫停 |
| 拖曳時間軸 | 跳到任意時間 |
| 點章節按鈕 / ← → 鍵 | 切換章節 |
| 匯出此畫面 PNG | 輸出目前畫面（2560×1440） |
| 匯出全部關鍵畫面 | 一次下載 14 張關鍵畫面 |

- 播放時滑鼠靜止約 3 秒，控制列會自動隱藏。
- 第一次批次匯出時，瀏覽器可能詢問是否允許下載多個檔案，請選擇允許。
- 網址加上 `?t=秒數`（例如 `?t=37.5`）可直接開在指定時間並暫停。

## 章節內容

| 時間 | 章節 | 對應系統流程 |
| --- | --- | --- |
| 0:00 | 研究小間 | 情境建立：從走廊穿過門上小窗進入單人小間 |
| 0:09 | 邊緣裝置 | 牆角裝置特寫：樹莓派 5、Arduino、MLX90640 |
| 0:17 | 資料處理 | 邊緣端主迴圈：校驗失敗丟棄 → 32×24 矩陣 → 插值放大 → 背景扣除 → 閾值偵測 → 連續 3 幀確認 |
| 0:29 | 熱成像 | 處理結果壓平成熱成像畫面 |
| 0:34 | 監控網頁 | 畫面拉遠成儀表板，再拉遠到櫃台螢幕 |
| 0:43 | 離席計時 | 使用者離開，狀態變化：使用中 → 暫時離開 → 無人時間超時 |
| 0:55 | 巡查處理 | 儀表板警示 → 工讀生現場確認 → 網頁填寫並送出巡查紀錄 |

## 備註

- 動畫內的人名、登記時段、時間與紀錄文字皆為示範用的模擬資料。
- 播放流暢度取決於電腦的顯示卡；較舊的筆電可能會稍微掉幀，匯出的 PNG 畫質不受影響。
